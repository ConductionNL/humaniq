**Status:** draft

## Data Model

### Entity: ApiKey

**Register:** openregister/infra  
**Schema:** ApiKey

Represents a scoped API credential for external consumers.

```json
{
  "id": "uuid",
  "tenant_id": "uuid",
  "name": "string (human-readable, e.g. 'Azure AD Provisioning')",
  "prefix": "string (visible prefix, e.g. 'hrmq_live_abc...')",
  "hashed_secret": "string (bcrypt or argon2)",
  "scopes": ["string (e.g. 'employees:read', 'employees:write', 'leave:read', 'scim:provision')"],
  "created_at": "timestamp",
  "created_by_user_id": "uuid",
  "last_used_at": "timestamp (nullable)",
  "expires_at": "timestamp (nullable)",
  "rate_limit_tier": "enum ('free', 'standard', 'enterprise')",
  "active": "boolean",
  "metadata": {
    "description": "string (optional notes)",
    "rotation_schedule": "string (e.g. 'monthly', nullable)"
  }
}
```

---

### Entity: Webhook

**Register:** openregister/infra  
**Schema:** Webhook

Represents a subscription to hrmq events.

```json
{
  "id": "uuid",
  "tenant_id": "uuid",
  "url": "string (HTTPS only)",
  "secret": "string (one-time returned, hashed on storage)",
  "event_types": [
    "enum ('employee.created', 'employee.updated', 'employee.terminated', 'leave.approved', 'org.restructured')"
  ],
  "active": "boolean",
  "created_at": "timestamp",
  "created_by_user_id": "uuid",
  "last_triggered_at": "timestamp (nullable)",
  "retry_policy": {
    "max_retries": "integer (default: 5)",
    "backoff_strategy": "enum ('exponential', default: 'exponential')",
    "initial_delay_ms": "integer (default: 1000)"
  },
  "metadata": {
    "description": "string (optional notes)",
    "disable_reason": "string (set when active=false due to consecutive failures)"
  }
}
```

### Entity: WebhookDelivery

**Register:** openregister/infra  
**Schema:** WebhookDelivery

Audit log entry for each webhook delivery attempt.

```json
{
  "id": "uuid",
  "webhook_id": "uuid (ref to Webhook)",
  "event_id": "uuid",
  "event_type": "string (e.g. 'employee.created')",
  "event_payload_summary": "string (truncated for display)",
  "attempt_number": "integer",
  "http_status": "integer (nullable if delivery not attempted yet)",
  "response_body_truncated": "string (first 500 chars of response body, nullable)",
  "delivered_at": "timestamp (nullable)",
  "next_retry_at": "timestamp (nullable)",
  "created_at": "timestamp"
}
```

### Entity: ScimResource (SCIM 2.0 Protocol Mapping)

Maps SCIM User and Group payloads to hrmq Employee and OrgUnit entities per RFC 7644.

**SCIM User → Employee Mapping:**
| SCIM Attribute | Employee Field | Required | Notes |
|---|---|---|---|
| id | id | Yes | Generated by hrmq, returned in response |
| userName | email | Yes | Unique per tenant |
| name.givenName | firstName | Yes | |
| name.familyName | lastName | Yes | |
| email[type=work].value | workEmail | Yes | |
| phone[type=work].value | workPhone | No | |
| urn:ietf:params:scim:schemas:extension:enterprise:2.0:User.manager | manager_id | No | Reference to Employee id |
| urn:ietf:params:scim:schemas:extension:enterprise:2.0:User.department | orgUnit_id | No | Reference to OrgUnit id |
| urn:ietf:params:scim:schemas:extension:enterprise:2.0:User.employeeNumber | externalId | No | |
| urn:ietf:params:scim:schemas:extension:enterprise:2.0:User.costCenter | costCenter | No | |
| urn:ietf:params:scim:schemas:extension:enterprise:2.0:User.division | division | No | |
| active | status | Yes | true → active, false → inactive |

**SCIM Group → OrgUnit Mapping:**
| SCIM Attribute | OrgUnit Field | Required | Notes |
|---|---|---|---|
| id | id | Yes | Generated by hrmq |
| displayName | name | Yes | |
| members[] | orgAssignments[] | No | Array of member ids |

## API Design

### REST Endpoints

**Base URL:** `/api/v1` (versioned)  
**Auth:** Bearer token (API key or OAuth token)  
**Pagination:** cursor-based, default 50 rows, max 250  
**Rate-limit headers:** X-RateLimit-Remaining, X-RateLimit-Reset  

```
GET    /api/v1/employees              → list employees
GET    /api/v1/employees/{id}         → get employee detail
POST   /api/v1/employees              → create employee (scope: employees:write)
PUT    /api/v1/employees/{id}         → replace employee
PATCH  /api/v1/employees/{id}         → update employee
DELETE /api/v1/employees/{id}         → delete employee (scope: employees:write)

GET    /api/v1/org-units              → list org-units
GET    /api/v1/org-units/{id}         → get org-unit detail

GET    /api/v1/leave-requests         → list leave-requests
GET    /api/v1/leave-requests/{id}    → get leave-request detail
POST   /api/v1/leave-requests         → create leave-request (scope: leave:write)
PATCH  /api/v1/leave-requests/{id}    → approve/reject leave-request

GET    /api/v1/openapi.json           → OpenAPI 3.1 spec
```

---

### GraphQL Endpoint

**URL:** `POST /api/v1/graphql`  
**Auth:** Bearer token (API key or OAuth token)  
**Query Depth Cap:** 7 levels (prevents runaway recursion)  
**Query Complexity Scoring:** configurable per rate-limit tier  

```graphql
type Query {
  employees(first: Int, after: String, filter: EmployeeFilter): EmployeeConnection!
  employee(id: ID!): Employee
  orgUnits(first: Int, after: String): OrgUnitConnection!
  orgUnit(id: ID!): OrgUnit
  leaveRequests(first: Int, after: String, filter: LeaveFilter): LeaveConnection!
}

type Employee {
  id: ID!
  firstName: String!
  lastName: String!
  email: String!
  workPhone: String
  manager: Employee
  orgUnit: OrgUnit
  recentLeave(limit: Int = 5): [LeaveRequest!]!
  startDate: Date
  endDate: Date
  status: String!
}

type OrgUnit {
  id: ID!
  name: String!
  parent: OrgUnit
  children: [OrgUnit!]!
  members: [Employee!]!
}

type LeaveRequest {
  id: ID!
  employee: Employee!
  type: String! # 'vacation', 'sick', 'unpaid', etc.
  startDate: Date!
  endDate: Date!
  status: String! # 'pending', 'approved', 'rejected'
  createdAt: DateTime!
}

# Cursor-based pagination connections
type EmployeeConnection {
  edges: [EmployeeEdge!]!
  pageInfo: PageInfo!
  total: Int!
}

type EmployeeEdge {
  cursor: String!
  node: Employee!
}

type PageInfo {
  hasNextPage: Boolean!
  endCursor: String
}
```

### SCIM 2.0 Endpoints

**Base URL:** `/scim/v2`  
**Auth:** Bearer token (API key scoped to scim:provision)  
**Format:** JSON, Content-Type: application/scim+json  

```
GET    /scim/v2/Users                 → list users (SCIM format)
GET    /scim/v2/Users/{id}            → get user detail (SCIM format)
POST   /scim/v2/Users                 → create user, maps to Employee
PUT    /scim/v2/Users/{id}            → full replace (SCIM semantics)
PATCH  /scim/v2/Users/{id}            → incremental update (RFC 6902 JSON Patch)
DELETE /scim/v2/Users/{id}            → deprovision (mark inactive, don't hard-delete)

GET    /scim/v2/Groups                → list groups (SCIM format), maps to OrgUnits
GET    /scim/v2/Groups/{id}           → get group detail
POST   /scim/v2/Groups                → create group, maps to OrgUnit
PUT    /scim/v2/Groups/{id}           → full replace
PATCH  /scim/v2/Groups/{id}           → incremental update
DELETE /scim/v2/Groups/{id}           → delete group

GET    /scim/v2/.well-known/scim-configuration  → SCIM provider config (RFC 7644 section 4)
GET    /scim/v2/Schemas               → SCIM schema list
GET    /scim/v2/Schemas/{schemaId}    → specific schema definition
```

---

### Webhook Subscription Endpoints

**Base URL:** `/api/v1` (versioned)  
**Auth:** Bearer token (API key or OAuth token)  

```
GET    /api/v1/webhooks               → list subscriptions
POST   /api/v1/webhooks               → create subscription, auto-verifies URL
GET    /api/v1/webhooks/{id}          → get webhook detail (secret hidden)
PATCH  /api/v1/webhooks/{id}          → update event_types or active status
DELETE /api/v1/webhooks/{id}          → delete subscription
POST   /api/v1/webhooks/{id}/test     → manually test with sample event

GET    /api/v1/webhooks/{id}/deliveries  → list delivery attempts (audit log)
GET    /api/v1/webhooks/{id}/deliveries/{deliveryId}  → detail of one attempt
POST   /api/v1/webhooks/{id}/deliveries/{deliveryId}/retry  → retry failed delivery
```

---

### API Key Management Endpoints

**Base URL:** `/api/v1` (versioned)  
**Auth:** Nextcloud user session (admin only)  

```
GET    /api/v1/settings/api-keys      → list tenant's API keys (scope hidden)
POST   /api/v1/settings/api-keys      → create new key (returns secret once)
GET    /api/v1/settings/api-keys/{id} → get key detail (scope shown, secret hidden)
PATCH  /api/v1/settings/api-keys/{id} → update name, rate_limit_tier, active status
POST   /api/v1/settings/api-keys/{id}/rotate  → generate new secret, mark old expired
DELETE /api/v1/settings/api-keys/{id} → revoke key

GET    /api/v1/settings/api-keys/{id}/stats   → usage stats (requests/day, last_used, error_rate)
```

## Reuse Analysis

This spec leverages existing OpenRegister + openconnector infrastructure:

- **ObjectService** — CRUD operations on ApiKey, Webhook, WebhookDelivery entities (no custom service needed)
- **AuthorizationService** — scope-based access control for API endpoints
- **WebhookService** (openconnector) — webhook delivery worker, retry logic, HMAC signature generation
- **ImportService** — seed data loading for mock objects
- **GraphQLController** (if available) — GraphQL endpoint handler
- **ConfigurationService** — API key settings UI

No duplication detected. This spec extends existing services with hrmq-specific entity types (ApiKey, Webhook) and endpoints.

---

## Cross-app Coordination

- **openconnector** — auth-protocol-suite provides OAuth2 server, JWT issuance, API-key validation primitives
- **openregister** — hosts ApiKey, Webhook, WebhookDelivery schemas in shared `infra` register
- **mydash** — consumes hrmq API metrics for dashboard widgets (requests/day, error rate)
- **n8n** — replaces ad-hoc n8n workflows with stable webhook subscriptions
- **opentalk** — Slack notifications subscribe to hrmq webhooks
- **employee-management** — source data (Employee entity)
- **org-chart-basic** — source data (OrgUnit entity)
