# IKB Rijk & Gemeenten — Design

## Data Model

Five core schemas in the `hrmq` register:

### IkbAccount

One per employee per calendar year. Represents the IKB budget container.

```json
{
  "@self": {
    "register": "hrmq",
    "schema": "IkbAccount",
    "slug": "acc-2026-jan-willemse-rijk"
  },
  "employeeId": "emp-284932",
  "cao": "rijk",
  "year": 2026,
  "openingBalance": 2045.50,
  "currentBalance": 1523.75,
  "accrualPercentage": 16.37,
  "pensionableBase": 2850.00,
  "lastAccrualDate": "2026-05-01",
  "status": "active",
  "createdAt": "2026-01-01T09:00:00Z",
  "createdBy": "sys-payroll-init"
}
```

**Fields:**
- `employeeId`: Reference to `employee-master` schema via `rel:EmployeeRef`
- `cao`: Enum `[rijk, gemeenten, custom]`
- `accrualPercentage`: Decimal, 2 decimal places (16.37%, 17.05%, etc.)
- `pensionableBase`: Gross monthly salary subject to IKB accrual
- `status`: Enum `[active, closed, frozen]` — frozen during payroll window

### IkbAccrual

Monthly ledger entry. Immutable once `lockedAt` is set.

```json
{
  "@self": {
    "register": "hrmq",
    "schema": "IkbAccrual",
    "slug": "accrual-2026-05-jan-willemse"
  },
  "accountId": "acc-2026-jan-willemse-rijk",
  "period": "2026-05",
  "pensionableSalary": 2850.00,
  "bovenwettelijkeComponenten": 450.00,
  "accrualAmount": 445.78,
  "runId": "payroll-run-2026-05",
  "payrollMutationRef": "mut-2026-05-12345",
  "lockedAt": "2026-06-01T06:00:00Z",
  "lockedBy": "sys-accrual-job",
  "metadata": {
    "prorationBasis": null,
    "suppressionReason": null
  }
}
```

**Fields:**
- `period`: YYYY-MM format
- `bovenwettelijkeComponenten`: Sum of vakantietoeslag, eindejaarsuitkering, toelagen
- `accrualAmount`: `(pensionableSalary + bovenwettelijkeComponenten) * accrualPercentage / 12`, rounded to 2 decimals
- `payrollMutationRef`: Reference to `payroll-engine-nl` mutation (informational only)
- `lockedAt`: Once set, entry is immutable for 7 years

### IkbChoice

Uitruil request (allocation of IKB budget to a benefit).

```json
{
  "@self": {
    "register": "hrmq",
    "schema": "IkbChoice",
    "slug": "choice-2026-04-fietsplan"
  },
  "accountId": "acc-2026-jan-willemse-rijk",
  "catalogItemId": "cat-fiets-van-de-zaak",
  "requestedAmount": 749.00,
  "requestedDate": "2026-04-15T14:22:00Z",
  "effectiveDate": "2026-05-01",
  "status": "approved",
  "fiscalImpact": {
    "grossDeduction": 749.00,
    "netImpact": -611.00,
    "loonheffingDelta": 138.00
  },
  "wkrCategory": "nihilwaardering",
  "supportingDocumentIds": [],
  "approverId": "mgr-284903",
  "decisionRationale": "Approved per CAO art. 4.5",
  "approvedAt": "2026-04-18T09:30:00Z"
}
```

**Fields:**
- `status`: Enum `[concept, submitted, approved, rejected, reversed, settled]`
- `fiscalImpact`: Computed on submission; shows gross-to-net delta
- `wkrCategory`: Enum `[gericht_vrijgesteld, nihilwaardering, vrije_ruimte, belast]`
- `supportingDocumentIds[]`: References to `docudesk` file records

### IkbCatalogItem

Curated list of benefits available for uitruil.

```json
{
  "@self": {
    "register": "hrmq",
    "schema": "IkbCatalogItem",
    "slug": "cat-fiets-van-de-zaak"
  },
  "code": "FIETS-NIHIL",
  "cao": "rijk",
  "category": "fiets",
  "displayName_nl": "Fiets van de zaak (nihil­waardering)",
  "displayName_en": "Bike of the business (nil valuation)",
  "minAmount": 100.00,
  "maxAmount": 2500.00,
  "requiresApproval": false,
  "requiresDocument": false,
  "wkrCategory": "nihilwaardering",
  "fiscalRule": "rule-fiets-nihilwaardering",
  "validFrom": "2026-01-01",
  "validUntil": null,
  "vendorId": null
}
```

**Fields:**
- `code`: Unique identifier (human-readable for audits)
- `category`: Enum `[salaris, verlof, opleiding, fiets, fitness, woon-werk, vakbond, uitkering]`
- `wkrCategory`: Determines fiscal treatment
- `fiscalRule`: Reference to a fiscal calculation strategy; resolver in `IkbFiscalRuleRegistry`

### IkbPayout

Year-end residual. Generated by the annual close job.

```json
{
  "@self": {
    "register": "hrmq",
    "schema": "IkbPayout",
    "slug": "payout-2025-jan-willemse"
  },
  "accountId": "acc-2025-jan-willemse-rijk",
  "year": 2025,
  "residualAmount": 487.50,
  "grossAmount": 487.50,
  "netAmount": 316.50,
  "loonheffing": 171.00,
  "payrollMutationRef": "mut-2025-12-payout-67890",
  "payoutDate": "2025-12-23",
  "createdAt": "2025-11-30T02:00:00Z",
  "createdBy": "sys-yearend-job"
}
```

**Fields:**
- `residualAmount`: Positive balance on cut-off date (default 30 November)
- `grossAmount`: Amount sent to payroll before loonheffing
- `netAmount`: Amount employee receives
- `loonheffing`: Withheld tax (calculated from `Loonheffingstabel`)

## API Design

### Endpoints

**Read-only (medewerker self-service):**
- `GET /hrmq/ikb/accounts/{id}` — fetch account balance + accrual history
- `GET /hrmq/ikb/accounts/{id}/choices` — fetch submitted choices + history
- `GET /hrmq/ikb/catalog` — fetch available catalog items filtered by CAO + current org config
- `POST /hrmq/ikb/simulate` — dry-run fiscal calculation for a proposed choice (no persistence)

**Write (medewerker + line manager):**
- `POST /hrmq/ikb/choices` — submit a new uitruil choice
- `PATCH /hrmq/ikb/choices/{id}` — edit a choice in concept status
- `DELETE /hrmq/ikb/choices/{id}` — withdraw a choice in concept status
- `POST /hrmq/ikb/choices/{id}/approve` — line manager approves (requires `role:MANAGER` on employee context)
- `POST /hrmq/ikb/choices/{id}/reject` — line manager rejects with rationale

**Admin (HR + payroll integration):**
- `POST /hrmq/ikb/accrual-run` — trigger monthly accrual job (idempotent, keyed by `runId`)
- `POST /hrmq/ikb/yearend-close` — trigger annual close job (generates `IkbPayout`)
- `GET /hrmq/ikb/admin/wkr-report` — WKR consumption summary (vrije ruimte headroom)
- `GET /hrmq/ikb/admin/audit-log` — immutable audit trail export
- `POST /hrmq/ikb/catalog-items` — HR admin adds or updates catalog (org-scoped)

## Reuse Analysis

**Existing OpenRegister services leveraged:**
- `ObjectService` — CRUD on IkbAccount, IkbAccrual, IkbChoice, IkbCatalogItem, IkbPayout
- `SchemaService` — schema registration + validation
- `AuditTrailService` — immutable audit logs per REQ-010
- `NotificationService` — approval workflow notifications
- `FileService` — supporting document storage (docudesk integration)
- `TasksController` — approval task creation and lifecycle

**No custom components needed:**
- List views / data tables → `CnDataTable`
- Create/edit forms → `CnFormDialog` (auto-generated from schema)
- Detail pages → `CnDetailPage`
- Dashboard → `CnDashboardPage` with KPI cards for balance + trend

## Frontend Structure

**Employee self-service view:**
- IKB Dashboard page (`views/DashboardPage.vue`)
  - Balance card (current + projected year-end)
  - Accrual history chart
  - Submitted choices list
  - "Simuleer een nieuwe keuze" CTA

**Simulation modal (`modals/IkbSimulationModal.vue`):**
  - Catalog picker
  - Amount input with min/max validation
  - Real-time fiscal preview (gross, net, loonheffing)
  - WKR category badge
  - Submit button

**Approval inbox (manager context):**
  - List of pending choices for direct reports
  - Batch approve / reject
  - Template rationales for quick rejection

## Security & Compliance

- **Authentication**: Nextcloud session-based; all endpoints require `OCP\IRequest`
- **Authorization**: Property RBAC on IkbChoice — only employee + line manager + HR roles can read
- **Audit**: Every state change writes `IkbAuditLog` with actor, IP, before/after snapshot
- **Data retention**: 7-year immutable retention per AWR art. 52; legal hold support
- **PII**: Seed data uses realistic Dutch names + BSNs; production anonymizes in exports
